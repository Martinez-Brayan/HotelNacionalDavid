# Hotel Nacional David

Landing page estática para el Hotel Nacional David.

## Preview en Vercel

1. Sube este proyecto a un repositorio de GitHub o selecciona la carpeta del proyecto desde Vercel.
2. Importa el proyecto en [Vercel](https://vercel.com/new).
3. Mantén estos valores:
   - **Framework Preset:** Other
   - **Build Command:** vacío
   - **Output Directory:** `.`
   - **Install Command:** vacío
4. Haz clic en **Deploy**.

La página principal está en `index.html`. No necesita compilación ni variables de entorno.

## Archivos principales

- `index.html`: entrada de la web.
- `Hotel.html`: copia editable de la página original.
- `styles.css`: estilos y diseño responsive.
- `script.js`: idioma, navegación y validaciones de formularios.
- `vercel.json`: configuración de URLs limpias.

Los formularios son actualmente una demostración front-end y todavía no envían reservas a un motor externo.
